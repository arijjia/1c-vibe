# Демо-задачи для Jira (создать в тестовом проекте, например INTAIDEV)

Три задачи нарастающей сложности для проверки MVP. Создай их в Jira как есть,
затем попроси агента: «выполни задачу INTAIDEV-XXX по скиллу 1c-vibe-demo».

## Задача 1 (простая: правка BSL)

**Тема:** Функция Приветствие: некорректная работа с пустым наименованием

**Описание:**

В модуле объекта справочника Товары функция `Приветствие(Товар)` при пустом
наименовании товара возвращает некрасивую строку «Привет, » (с висящей
запятой и пробелом).

Ожидаемое поведение: если передан пустой товар или его наименование пустое,
функция должна возвращать строку «Привет, безымянный товар».

Критерии приёмки:

- Когда я вызываю `Приветствие` с пустой ссылкой или пустым наименованием,
  тогда получаю «Привет, безымянный товар»;
- Когда наименование заполнено, тогда поведение не меняется.

## Задача 2 (средняя: правка метаданных XML)

**Тема:** Добавить реквизит «Артикул» в справочник Товары

**Описание:**

Для складского учёта нужен реквизит «Артикул» (строка неограниченной длины
с контролем уникальности на уровне обработки в модуле — без изменения
структуры кода, только метаданные).

Критерии приёмки:

- В `Object.xml` справочника Товары появляется атрибут «Артикул» (тип строка,
  длина 50, переменная);
- Существующие атрибуты не изменились;
- BSL-модули не затронуты.

## Задача 3 (посложнее: новый код + документация)

**Тема:** Функция расчёта цены с НДС в модуле менеджера

**Описание:**

В модуле менеджера справочника Товары уже есть функция `СуммаНДС(Сумма, СтавкаНДС)`.
Нужна парная экспортная функция `ЦенаСНДС(Сумма, СтавкаНДС)`, возвращающая
сумму с учётом НДС, с проверкой отрицательных значений: при отрицательной
сумме или ставке — вызывать исключение (`ВызватьИсключение`) с понятным текстом.

Критерии приёмки:

- Функция экспортная, есть комментарий в формате `// Параметры: ...`;
- `ЦенаСНДС(100, 20)` = 120;
- При отрицательных параметрах выбрасывается исключение;
- Существующая функция `СуммаНДС` не изменилась.

## Задача 4 (баг-фикс BSL)

**Тема:** СуммаНДС: округлять результат до копе

- `СуммаНДС(99.99, 20)` = 19.998 → должно быть 20 (округление до 2 знаков);
- деление без остатка (100, 20) — значение не меняется;
- вызовы СуммаНДС в коде не правятся.

## Задача 5 (правка метаданных XML)

**Тема:** Добавить реквизит «Штрихкод» в справочник Товары

- атрибут «Штрихкод»: строка, длина 13, фиксированная, в Object.xml;
- остальные реквизиты и BSL-модули не затронуты.

## Задача 6 (новый код + тесты)

**Тема:** Функция ЦенаБезНДС + юнит-тесты в модуле менеджера

- экспортная `ЦенаБезНДС(Сумма, СтавкаНДС)`: ЦенаБезНДС(120, 20) = 100;
- отрицательные параметры → ВызватьИсключение;
- СуммаНДС и ЦенаСНДС не изменились; в MR — отчёт прогона юнит-тестов.
