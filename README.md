# 1c-vibe

AI-агенты для разработки 1С: продукт для автоматизации полного цикла задач 1С-разработки (ЦИТ ТюмГУ).

Цикл: аналитика/постановка (Jira) → разработка (Конфигуратор, git) → код-ревью (GitLab + SonarQube) → тестирование (автотесты + GUI-агент) → деплой → поддержка.

Ключевая идея: агент берёт задачу в Jira, работает с кодом в git-ветке, разворачивает тестовую базу из ночного бэкапа в изолированном контуре, сам себя проверяет и присылает merge request с пруфами (логи, скриншоты, отчёты тестов). Человек контролирует и вмерживает.

## Структура репозитория

```
mvp/       — каркас «Jira → код → MR → комментарий» (скрипты, скилл, демо-проект)
agent/     — целевая агентская петля (чистый Python, OpenAI-совместимый API)
win/       — подготовка Windows-машины контура (bootstrap.ps1)
docs/      — документация целевой стадии (по мере появления)
```

- План и архитектура MVP: `docs/mvp-plan.md`
- Код и инструкция запуска MVP: `mvp/README.md`
- Скилл агента: `mvp/skills/1c-vibe-demo/SKILL.md`

## Целевая агентская петля (`agent/`)

Самодостаточный рантайм без внешних зависимостей (только stdlib): модель
по OpenAI-совместимому `/chat/completions` + инструменты (shell, файлы,
CLI проекта) + скилл из `mvp/skills/1c-vibe-demo/`.

Цепочка провайдеров (первый доступный побеждает):
1. корпоративный LiteLLM ЦИТ (`https://litellm-dev.utmn.ru/v1`, qwen-3.8-*),
   доступен из корпоративной сети/VPN;
2. резервный (z.ai coding API) — если контур недоступен.

Запуск (машина с доступом к LLM/Jira/GitLab — например, Windows-машина контура):

```
win\bootstrap.ps1                                  # подготовка машины
python agent\llmcheck.py                           # проверка связи с моделями
python agent\loop.py --task INTAIDEV-101 --workspace mvp\dump
```

Безопасность петли: инструменты ограничены workspace; список запрещённых
команд отсекает деструктив; все вызовы пишутся в `audit.log`; лимит ходов.

## Дорожная карта (кратко)

- MVP (готов): Jira → ветка → правка → BSL-линт → MR → комментарий.
- Цель (текущая): та же петля на Windows-машине контура + тестовая база
  1С (ibcmd: restore бэкапа → import XML → check) + пруфы (отчёты, скриншоты).
- Далее: YAxUnit/Vanessa, мост git→хранилище 1С в полуавтомате, GUI-петля.

Исследовательская документация и журналы — в приватной репе 1c-vibe-hq.
