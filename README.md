# 1c-vibe

AI-агенты для разработки 1С: продукт для автоматизации полного цикла задач 1С-разработки (ЦИТ ТюмГУ).

Цикл: аналитика/постановка (Jira) → разработка (Конфигуратор, git) → код-ревью (GitLab + SonarQube) → тестирование (автотесты + GUI-агент) → деплой → поддержка.

Ключевая идея: агент берёт задачу в Jira, работает с кодом в git-ветке, разворачивает тестовую базу из ночного бэкапа в изолированном контуре, сам себя проверяет и присылает merge request с пруфами (логи, скриншоты, отчёты тестов). Человек контролирует и вмерживает.

## Структура репозитория

```
mvp/       — каркас «Jira → код → MR → комментарий» (скрипты, скилл, демо-проект)
win/       — контурная цепочка 1С (contour-*.ps1) + legacy B3-доставка (см. ниже)
docs/      — документация (целевое решение: docs/agctl-only.md)
```

> **Целевой путь — только через agctl** (решение `docs/agctl-only.md`).
> Бинарь agctl создаёт рабочее место 1c-vibe и запускает dsh web в контейнере;
> сначала CLI-first без веб-панели ЛК, затем сервер. Режимы B1 (dsh на хосте),
> B2 (dsh-home в репе) и B3 (петля `agent/`) — legacy: не поддерживаются,
> код на месте до отдельного аудита удаления.

- План и архитектура MVP: `docs/mvp-plan.md`
- Код и инструкция запуска MVP: `mvp/README.md`
- Скилл агента: `mvp/skills/1c-vibe-demo/SKILL.md`

## Целевой запуск — через agctl (петля `agent/` — legacy B3)

Агент работает в **dsh web внутри agctl-контейнера**, модель и токен задаются
при создании рабочего места в agctl. Самописная Python-петля `agent/`
(`loop.py` + `guard.py`/`llmcheck.py`) и её точка входа `win\bootstrap.ps1` —
legacy B3: не поддерживается, не развивать (подробности — `docs/agctl-only.md`).

Доменный тулкит (`mvp/`: Jira/GitLab-клиенты, `publish.py`, `lint.py`, скилл)
едет в agctl-шаблон 1c-vibe как есть и вызывается агентом внутри рабочего места.

## Дорожная карта (кратко)

- MVP (готов): Jira → ветка → правка → BSL-линт → MR → комментарий.
- Цель (текущая): тот же цикл из agctl-рабочего места + тестовая база
  1С (ibcmd: restore бэкапа → import XML → check) + пруфы (отчёты, скриншоты).
- Далее: YAxUnit/Vanessa, мост git→хранилище 1С в полуавтомате, GUI-петля.

Исследовательская документация и журналы — в приватной репе 1c-vibe-hq.
