# 1c-vibe

AI-агенты для разработки 1С: продукт для автоматизации полного цикла задач 1С-разработки (ЦИТ ТюмГУ).

Цикл: аналитика/постановка (Jira) → разработка (Конфигуратор, git) → код-ревью (GitLab + SonarQube) → тестирование (автотесты + GUI-агент) → деплой → поддержка.

Ключевая идея: агент берёт задачу в Jira, работает с кодом в git-ветке, разворачивает тестовую базу из ночного бэкапа в изолированном контуре, сам себя проверяет и присылает merge request с пруфами (логи, скриншоты, отчёты тестов). Человек контролирует и вмерживает.

## Текущий этап: MVP «Jira → код → MR → комментарий»

Первый работающий цикл: агент читает задачу в Jira, правит код демо-репозитория
GitLab (синтетическое дерево 1С: XML + BSL), открывает Merge Request и
оставляет комментарий в задаче. Проверка правок — статический анализ
BSL Language Server (headless, платформа 1С не нужна).

- План и архитектура MVP: `docs/mvp-plan.md`
- Код и инструкция запуска: `mvp/README.md`
- Скилл агента: `mvp/skills/1c-vibe-demo/SKILL.md`

Следующие шаги после MVP: реальное дерево конфигурации в git → тестовый
контур (ibcmd, база из бэкапа) → автотесты (YAxUnit, Vanessa) →
мост git → хранилище 1С с подтверждением человека.

Исследовательская документация и полный роадмап — в приватной репе 1c-vibe-personal.
