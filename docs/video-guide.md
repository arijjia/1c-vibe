# Видео-гайд v2: сквозной прогон 1c-vibe через agctl (сценарий съёмки)

Статус: съёмочный сценарий. Пошаговая версия с командами —
[handover-mvp.md](handover-mvp.md) (§4). Хронометраж ~15–17 минут.

## Подготовка за кадром

- Docker Desktop запущен, VPN включён; токены: Jira, GitLab, LiteLLM.
- Терминал 1 — сервер `make demo`; браузер; терминал 2 — работа в воркспейсе.

## Сцены по порядку

1. **Что где лежит (1 мин, слайд).** Два репо: `agctl` — платформа (бинарь,
   ЛК, provision, Docker, секреты); `1c-vibe` — домен 1С (тулкит Jira/GitLab,
   скилл, демо-проект). Шаблон 1c-vibe вшит в бинарь и раскладывается в каждое
   рабочее место. Никакого dsh на хосте ставить не нужно.
2. **Запуск (1 мин).** `cd agctl && make demo` → лог сборки →
   `serve: addr=http://127.0.0.1:8929` → открыть в браузере.
3. **Регистрация + рабочее место (2 мин).** Первый юзер = admin. Создать место:
   имя `1c-demo`, шаблон **1c-vibe**, Base URL litellm, модели
   qwen-3.8-deep/fast, токен → статус `running` → «Открыть» → dsh web.
   Сказать: «платформа сама создала bare-репу, клон и контейнер».
4. **(30 сек, опционально) CLI-путь оператора.** Второй терминал:
   `agctl workspace create --user … --template 1c-vibe …` — то же самое без
   кликов.
5. **Контур внутри (2 мин).** Терминал dsh web:
   `cd scripts && cp .env.example .env` (вписать JIRA/GITLAB) →
   `python3 -m pytest tests/ -q` → 14 passed.
6. **Задача агенту (4–5 мин, сердце).** Сначала показать постановку:
   `python3 jira_client.py get INTAIDEV-3` (ЦенаСНДС). Потом фраза в чате:
   «выполни INTAIDEV-3 по скиллу 1c-vibe-demo». Ускоренно: ветка → правка BSL →
   линт → publish. Сказать: «я только смотрю».
7. **Пруфы (1 мин).** GitLab: MR с диффом и CI. Jira: комментарий агента.
   Ревью и merge — человек.
8. **Живучесть (1 мин).** ЛК → Stop → Start → файлы/сессии на месте. Сказать:
   «контейнер расходный, работа в git и DSH_HOME на диске, autosave каждые
   2 минуты».
9. **(30 сек, опционально) Триггер по метке.** В Jira метка `agent-run` → в
   логе сервера `jira-poll: INTAIDEV-N → очередь`. Сказать: «поллер кладёт
   задачу в очередь рабочего места; запуск агента по метке — следующий шаг».
10. **Под капотом за 2 мин (слайд).** В контейнер смонтированы клон
    (/workspace) и DSH_HOME (/home/dsh); bare — git-память; секреты —
    AES-GCM в БД + env; Windows-контур 1С — отдельная VM, будущий мост.

## Монтаж

- Токены и `?token=` в URL — блюр; `docker logs` целиком не показывать.
- Сцены 4, 9 — можно вырезать, если хронометраж горит.
